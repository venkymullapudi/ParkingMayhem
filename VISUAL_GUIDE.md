## Unity Interface Overview

### 1. Unity Hub
![Unity Hub Interface](https://docs.unity3d.com/uploads/Main/UnityHubProjects.png)
- Projects tab: Manage your Unity projects
- Installs tab: Manage Unity versions
- Learn tab: Access tutorials and resources

### 2. Unity Editor
![Unity Editor Interface](https://docs.unity3d.com/uploads/Main/UnityInterface.png)
1. Scene View: Build and edit your game
2. Game View: Preview your game
3. Hierarchy: List of game objects
4. Project Window: Project files
5. Inspector: Object properties
6. Console: Debug messages

## Project Setup

### 1. Creating a New Project
![New Project Dialog](https://docs.unity3d.com/uploads/Main/UnityHubNewProject.png)
1. Click "New Project"
2. Select 2D template
3. Name your project
4. Choose location
5. Click "Create"

### 2. Project Structure
![Project Structure](https://docs.unity3d.com/uploads/Main/ProjectWindow.png)
- Create folders for organization
- Import assets into appropriate folders
- Use meaningful names

## Scene Creation

### 1. Creating a New Scene
![New Scene Menu](https://docs.unity3d.com/uploads/Main/FileMenuNewScene.png)
1. File > New Scene
2. Choose 2D template
3. Save scene in Scenes folder

### 2. Adding GameObjects
![Create Menu](https://docs.unity3d.com/uploads/Main/GameObjectMenu.png)
1. Right-click in Hierarchy
2. Select 2D Object
3. Choose Sprite or other object

### 3. Configuring Components
![Inspector Window](https://docs.unity3d.com/uploads/Main/InspectorWindow.png)
1. Select GameObject
2. View Inspector
3. Add/modify components

## Script Creation

### 1. Creating a Script
![Create Script](https://docs.unity3d.com/uploads/Main/CreateScript.png)
1. Right-click in Project window
2. Create > C# Script
3. Name the script

### 2. Script Editor
![Script Editor](https://docs.unity3d.com/uploads/Main/MonoDevelop.png)
1. Double-click script to open
2. Write code
3. Save changes

### 3. Attaching Scripts
![Add Component](https://docs.unity3d.com/uploads/Main/AddComponent.png)
1. Select GameObject
2. Click Add Component
3. Select script
